## キャンペーン

`src/data/gym.ts` の `campaign` を編集します。

```ts
export const campaign = {
  enabled: true,
  startsAt: '2027-04-01T00:00:00+09:00',
  endsAt: '2027-05-31T23:59:59+09:00',
  title: '入会金無料キャンペーン',
  description: '確定した対象者・人数・申込条件などを記載',
};
```

日付は編集方法の例。現在は実施条件が未確定のため `enabled: false` です。タイトル、条件、日本時間の開始・終了日時を決めてから有効にしてください。

トップ画像下のお知らせ欄に続けて告知を表示します。閲覧端末の時刻を使い、開始前・終了後は非表示。判定は読込時・1分ごと・タブ再表示時に実施。設定変更後は再ビルド・再公開が必要ですが、一度公開した告知の期間終了はブラウザ側で判定します。

上記は登録方法の例。現在は記事未提供のため空配列です。登録後はお知らせ欄の下に開閉式の記事一覧が表示されます。

## GSAP・Lenisによる演出と追加画像

スクロール演出は `src/scripts/motion.ts`、追加レイアウトは `src/styles/motion.css` で管理しています。既存の依存パッケージ `gsap` と `lenis` を利用し、パッケージの追加・更新は行っていません。

- Lenisのスクロール処理をGSAP tickerで駆動し、ScrollTriggerと同期。
- ヒーローの見出しを行ごとに表示し、本文・ボタンを順に表示。
- スクロールに連動したヒーロー画像・手元写真・入会案内写真のパララックス。
- 各見出しと内容の登場、入会ステップ・設備項目の順次表示。
- ミット打ち・サンドバッグ・フットワークの3枚による写真ギャラリー。
- PCの幅1061px以上・高さ740px以上ではギャラリーを固定し、縦スクロールに合わせて写真を横に展開。その他の画面・動きを減らす設定・JavaScript無効時は通常の横スクロール。
- ギャラリーはキーボードでも閲覧可能。スマートフォンのタッチ操作は標準操作を維持。
- OSの「動きを減らす」設定ではLenisとGSAPの演出を停止。閲覧中の設定変更にも対応。
- モバイルメニューを開いている間はLenisを停止し、閉じた後に再開。
- 地図・記事の開閉、キャンペーン表示変更、画像・フォント読み込み時にスクロール位置計算を更新。
- スクロールヒントは縦文字と下方向に流れるラインへ変更。ヘッダー下の罫線・ナビのアンダーラインを削除。
